3. ❌ PROBLEMA IDENTIFICADO: Android 14 + Microfone

   **Sintoma:**
   - termux-microphone-record trava indefinidamente quando chamado via ADB/su
   - Mesmo com permissões corretas
   - Exit code 124 (timeout)

   **Causa Raiz:**
   - Android 14 tem restrições de segurança no acesso ao microfone
   - Microfone só funciona em apps em PRIMEIRO PLANO
   - Comandos via ADB/su são considerados "background"
   - É comportamento esperado do Android, não um bug

   **Evidências:**
   - 6 processos termux-api ficaram travados (PID 20579, 25225, etc.)
   - termux-volume funciona (não precisa de primeiro plano)
   - termux-microphone-record --help funciona (não acessa hardware)
   - Gravação com timeout sempre retorna 124
   - Dumpsys confirmou: RECORD_AUDIO granted=true

4. ✅ SOLUÇÃO: Teste Interativo
   - Usuário precisa executar testes DENTRO do app Termux
   - Não via ADB
   - Script test-mic-direct.sh criado para isso

🔍 LIÇÕES APRENDIDAS
═══════════════════════════════════════════════════════════════════════════════

1. Android 14+ tem restrições fortes no acesso ao microfone via background
   → Não é possível testar gravação via ADB/su
   → Testes precisam ser feitos dentro do app interativamente

2. Whisper.cpp compilado com CMake usa estrutura build/bin/
   → Diferente de compilação com Makefile (raiz)
   → Sempre verificar estrutura real antes de assumir

3. Permissões via pm grant não são suficientes para microfone
   → Android precisa que app esteja em primeiro plano
   → Usuário pode precisar conceder via UI do sistema

4. Processos termux-api podem travar indefinidamente
   → Sem mensagem de erro clara
   → Usar timeout para detectar travamentos
