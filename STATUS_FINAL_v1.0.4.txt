📊 RESUMO TÉCNICO
═══════════════════════════════════════════════════════════════════════════════

ARQUITETURA IMPLEMENTADA:
──────────────────────────────────────────────────────────────────────────────
  1. Gravação: termux-microphone-record → .m4a (formato nativo Android)
  2. Conversão: ffmpeg m4a → wav 16kHz mono (requerido pelo Whisper)
  3. Transcrição: whisper.cpp small model → texto
  4. Roteamento: intent_router.py → ações (volume, música, etc.)

FLUXO DE DADOS:
──────────────────────────────────────────────────────────────────────────────
  Microfone → m4a ($TMPDIR) → ffmpeg → wav ($TMPDIR) → Whisper → texto
                                                              ↓
                                                        intent_router
                                                              ↓
                                              termux-volume / termux-media-player

CORREÇÕES APLICADAS:
──────────────────────────────────────────────────────────────────────────────
  • /tmp → $TMPDIR (Termux não tem /tmp)
  • .wav → .m4a (formato nativo do termux-microphone-record)
  • sleep adicionado (gravação é assíncrona)
  • expanduser() → paths absolutos (funciona via su)
  • Suporte a modelo small (465MB, mais preciso)
  • Conversão automática de formatos
